# 🖼️ Image Gallery

A responsive and interactive **Image Gallery** built using **HTML, CSS, and JavaScript**. This project was created as part of the **CodeAlpha Internship**.

## 📌 Project Overview

This image gallery allows users to browse images through a clean and responsive interface. It includes navigation controls, a lightbox view, smooth animations, and interactive hover effects.

## ✨ Features

* 🖼️ Responsive image gallery layout
* ⬅️ Previous and ➡️ Next navigation buttons
* 🔍 Lightbox view for displaying images in a larger format
* 🖱️ Hover effects on images
* ✨ Smooth transitions and animations
* 📱 Responsive design for mobile, tablet, and desktop
* 🗂️ Image categories/filters
* ❌ Close button for the lightbox
* ⌨️ Easy navigation between images

## 🛠️ Technologies Used

* **HTML5** – Structure of the image gallery
* **CSS3** – Layout, styling, hover effects, and transitions
* **JavaScript** – Image navigation, lightbox functionality, and filters

## 🎯 Project Requirements

* Design an image gallery using HTML and CSS.
* Use JavaScript for image navigation.
* Add **Next** and **Previous** buttons.
* Implement a **lightbox view**.
* Add hover effects to gallery images.
* Add smooth transitions and animations.
* Make the gallery responsive for different screen sizes.
* Add image filters/categories as a bonus feature.

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/rudra-narayan-malla/codealpha-image-gallery
```

2. Open the project folder.

3. Make sure your images are inside the `images` folder.

4. Open `index.html` in your browser.

The image gallery is ready to use! 🎉

## 🖥️ Gallery Functions

### Navigation

Users can move between images using:

* **Next** button
* **Previous** button

### Lightbox

Clicking an image opens it in a larger **lightbox view**.

### Filters

Users can select different categories to display specific images.

### Responsive Design

The gallery automatically adjusts its layout according to the screen size.
